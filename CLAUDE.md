# CLAUDE.md

Website for Lucy Appleby's bat mitzvah (March 20, 2027, Park Slope). Read `README.md` first for layout, commands, and setup.

## Stack

Vite + Vue 3 (script setup, plain JS), Supabase (Postgres, Auth, Storage), Cloudflare Pages with one Pages Function for CloudMailin. No other backend.

## Canonical files

- `src/content.js`: all public copy and photo choices. Change words here, not in components.
- `src/admin/emailTemplate.js`: the contact email. Plain table HTML with the heading lettering baked into `public/email/*.jpg` (`scripts/render-email-art.cjs`; rerun it if the headings in `copy.contact` change).
- `src/lib/contact.js`: the contact card (`contactBlocks`, `missingFrom`) and address and family formatting. The page, the email, and the admin all use it.
- `src/components/journey/world.js`: the map for the 8-bit game. `art.json` and `public/journey/` are generated by `npm run journey`; never edit them by hand.
- `src/styles/base.css`: color tokens, fonts, buttons, fields. `dive.css` is Meet Lucy, `address.css` the contact and Coming soon pages, `admin.css` the admin.
- `shared/public-config.js`: `SITE_URL` (https://www.lucybatmitzvah.com, the canonical address), Supabase URL and publishable key. Imported by both `src/` and `functions/`. Public values only. Anything a guest receives (personal links, the shared form link, email pictures) is built from `SITE_URL`, never `window.location.origin`.
- `supabase/migrations/`: the schema. The hosted database must always match these files.
- `functions/api/send-email.js`: the only server code and the only place secrets are read. Sends through CloudMailin's HTTP API using the SMTP credentials (`CLOUDMAILIN_SMTP_URL`, or `CLOUDMAILIN_SMTP_USERNAME` and `CLOUDMAILIN_SMTP_PASSWORD`), plus `EMAIL_FROM`. Keep each call under the free plan's 50 outgoing requests (`MAX_MESSAGES`, and the chunk size in `src/admin/Email.vue`). `email_log.postmark_id` holds the CloudMailin message id.

## Rules

- Propose before changing architecture: schema, auth, routing, hosting, or the security model below.
- Visitors never touch tables directly. New public behavior means a new `security definer` function with `set search_path = ''`, input length checks, and an explicit `grant execute ... to anon, authenticated`. Keep RLS on every table.
- A valid personal token may return that household's contact card (envelope name, address, phone, email, main contact's name, family names and relationships) so they can confirm it. Never notes, groups, or other households. Without a valid token, return nothing about any household.
- Each household has exactly one main contact (`guests.is_primary`). Birthdays are not collected (the old `guests.birthday_*` columns are unused).
- A contact card missing its address, phone, or email asks for it (Add missing info) instead of offering Confirm info.
- Schema changes are new timestamped files in `supabase/migrations/`, written so they can be re-run (`if not exists`, `create or replace`, `drop policy if exists`). Apply with `npm run db:push`. Do not edit the database by hand.
- Secrets go in Cloudflare Pages settings and `.dev.vars`, never in the repo or in `shared/public-config.js`.
- The site is unlisted and must not be indexed, archived, or used for AI training. Keep the robots, googlebot, and bingbot meta tags and the canonical link in `index.html`, the block everything `robots.txt` with its named AI crawlers, and the `X-Robots-Tag` header in `public/_headers`. Keep the three robots values identical. The canonical address is `https://www.lucybatmitzvah.com`; it must match `SITE_URL`.
- Art in `public/art/` is cut from the family's save the date. New art must match it: marker and colored pencil look, the palette in `base.css`. No characters from films or books, anywhere on the site.
- The game in `components/journey/` is deliberately 8-bit: whole pixels only (1 pixel = 8 world units), flat colors, dark outlines, the Press Start 2P font. Characters are light cartoons, not likenesses, and no photo faces. Lucy moves only with left and right input (arrow keys, the on screen buttons, sideways swipes); never take over vertical page scrolling. At color war, Lucy and her camp friends are on the gold team (`C.gold` in `scripts/journey/draw.mjs`), never blue.
- Do not put real guest names or addresses in code, tests, or fixtures. Use made-up names.
- All motion must respect `prefers-reduced-motion` (see the block at the end of `dive.css`).
- `/movie` must stay pure CSS animation with absolute delays on one timeline. No JavaScript timers, or `scripts/render-movie.cjs` cannot export it.
- Destructive admin actions use a two-click confirm on the button, not `window.confirm`.

## Writing style

American English. No em dashes, en dashes, or clause-joining hyphens in any copy, comments, or docs. Sentence case. Plain verbs. Buttons say what they do.

## Git

Single working checkout, no worktrees. Do not commit or push. Hand over one copy-pasteable shell block (`cd`, `git add`, `git commit`, `git push`). Commit messages are one plain subject line with no body and no trailers.

## After every change

Update `README.md` and this file, and remove anything in them that is no longer true.
